# 프로젝트 개요: 온라인 강의 플랫폼

## 📋 프로젝트 정보

- **프로젝트명**: 온라인 강의 플랫폼 웹사이트
- **난이도**: ⭐⭐⭐⭐ (상)
- **예상 소요 시간**: 22-28시간
- **주요 기술**: HTML, CSS, JavaScript, 반응형 디자인, 비디오 플레이어

---

## 🎯 프로젝트 목표

이 프로젝트를 완료하면 다음을 할 수 있습니다:

- 강의 목록/상세/수강 시스템 구현(비디오 플레이어 포함)
- 학습 진도 관리 및 수강 완료 처리
- 강의 검색/필터링/카테고리 시스템
- 수강생/강사 역할 구분 및 프로필 관리
- 수강 후기 및 평점 시스템
- 실무에서 중요한 "미디어 처리/진도 관리/사용자 경험" 감각 익히기

---

## 📖 프로젝트 배경

온라인 강의 플랫폼은 교육 콘텐츠를 제공하고 학습자를 관리하는 핵심 서비스입니다.  
이 프로젝트에서는 "강의 탐색 → 수강 신청 → 학습 → 완료" 등 온라인 교육의 핵심 흐름을 직접 구현하면서,  
단순 페이지 제작을 넘어서 **미디어 기반 UI + 학습 진도 관리 + 사용자 역할 구분**을 경험합니다.

---

## 🎓 학습 목표

### 기술적 목표

- ✅ 복잡한 레이아웃 구조 설계(강의 목록/상세/수강 화면)
- ✅ 비디오 플레이어 통합 및 재생 제어
- ✅ 학습 진도 관리 시스템 구현(진행률/완료 상태)
- ✅ 강의 데이터 관리 및 표시(목록/상세/검색/필터/카테고리)
- ✅ 사용자 역할 구분(수강생/강사) 및 권한 관리
- ✅ 반응형 디자인 구현(모바일 우선 설계)

### 도구 활용 목표

- ✅ Notion으로 프로젝트 문서화(요구사항/이슈/회고)
- ✅ Figma로 디자인 시스템 구축(컬러/타이포/컴포넌트)
- ✅ GitHub로 버전 관리(PR/커밋 단위)
- ✅ Slack으로 협업 소통(피드백/리뷰)

## 🧭 프로젝트 범위(중요)

### 포함(필수)

- 메인 페이지(인기 강의/신규 강의/카테고리별)
- 강의 목록 페이지(검색/필터/정렬/페이지네이션)
- 강의 상세 페이지(강의 정보/커리큘럼/후기/수강 신청)
- 강의 수강 페이지(비디오 플레이어/진도 표시/강의 자료)
- 학습 대시보드(내 강의/진행률/완료 강의)
- 사용자 인증(회원가입/로그인/로그아웃)
- 프로필 페이지(수강생/강사)
- 수강 후기 및 평점 시스템

### 제외(이번 프로젝트에서는 다루지 않음)

- 실제 서버/DB/권한 시스템(백엔드)
- 실서비스급 보안(토큰/세션/암호화)
- 실제 비디오 스트리밍 서버 연동(로컬 비디오 파일 사용)
- 결제 시스템 연동(실서비스 결제는 범위 조절 필요)
- 실시간 채팅/질문 답변

실무 느낌은 내되, 실습 범위를 벗어나는 기능은 "구조만 이해"하는 정도로 제한합니다.

## 📝 요구사항 정의

### 0) 공통 요구사항

- **데이터 단위 정의**
  - 강의: `id, title, instructorId, instructor, category, price, thumbnail, description, curriculum, duration, level, rating, reviews, students`
  - 강의 섹션: `id, courseId, title, order, lessons`
  - 강의 레슨: `id, sectionId, title, videoUrl, duration, order, isPreview`
  - 수강 정보: `userId, courseId, progress, completedLessons, enrolledAt, lastAccessedAt`
  - 후기: `id, courseId, userId, userName, rating, content, createdAt`
- **가격 표기 규칙**
  - 원화 표기(예: `₩49,000`) + 천 단위 콤마
  - 무료 강의: "무료" 또는 "₩0"
- **상태(상황) 처리**
  - 로딩 중 / 결과 없음 / 오류 / 성공(토스트) 상태 최소 1개 이상 제공

### 필수 기능

1. **메인 페이지**

   - 헤더 (로고, 네비게이션, 검색, 로그인/프로필)
   - 히어로 섹션 (강력한 메시지 + CTA)
   - 인기 강의 섹션 (평점/수강생 수 기준)
   - 신규 강의 섹션
   - 카테고리별 강의 섹션
   - 푸터 (회사정보/문의/정책 링크)

   ✅ **권장 UX**

   - 강의 카드에 썸네일/제목/강사/가격/평점/수강생 수 표시
   - "더보기" 또는 "전체 보기" 링크

2. **강의 목록 페이지**

   - 강의 그리드 레이아웃
   - 필터링 (카테고리, 가격, 난이도, 평점)
   - 정렬 (인기순/최신순/가격순/평점순)
   - 검색 (제목/강사명/설명)
   - 페이지네이션 또는 더보기(둘 중 1개는 반드시)

   ✅ **권장 UX**

   - 필터 초기화 버튼
   - 검색 결과 "n개 강의" 표시
   - 스켈레톤(또는 로딩 스피너)

3. **강의 상세 페이지**

   - 강의 썸네일/비디오 미리보기
   - 강의 정보 (제목, 강사, 가격, 평점, 수강생 수)
   - 강의 설명
   - 커리큘럼 (섹션/레슨 목록, 미리보기 표시)
   - 수강 후기 및 평점
   - 수강 신청 버튼 (무료 강의는 즉시 수강 가능)

   ✅ **필수 예외**

   - 존재하지 않는 id 접근 시: "강의를 찾을 수 없음" 안내
   - 이미 수강 중인 강의: "수강하기" 버튼으로 변경

4. **강의 수강 페이지**

   - 비디오 플레이어 (HTML5 video 또는 iframe)
   - 강의 정보 사이드바 (커리큘럼, 강의 자료)
   - 학습 진도 표시 (진행률, 완료한 레슨)
   - 이전/다음 레슨 네비게이션
   - 레슨 완료 체크박스

   ✅ **필수 기능**

   - 비디오 재생 위치 저장 (localStorage)
   - 레슨 완료 시 진도 업데이트
   - 모든 레슨 완료 시 수강 완료 처리

5. **학습 대시보드**

   - 내 강의 목록 (수강 중/완료)
   - 학습 진도 요약 (전체 진행률, 완료 강의 수)
   - 최근 학습한 강의
   - 수강 예정 강의 (신청했지만 아직 시작 안 함)

6. **사용자 인증**

   - 회원가입 (이름/이메일/비밀번호/역할 선택: 수강생/강사)
   - 로그인 (이메일/비밀번호)
   - 로그아웃
   - 자동 로그인 (선택: localStorage)

   ✅ **필수 검증**

   - 이메일 형식 확인
   - 비밀번호 확인 일치
   - 중복 이메일 확인

7. **프로필 페이지**

   - 사용자 정보 (아바타/이름/역할/가입일)
   - 수강생: 내 강의 목록, 학습 통계
   - 강사: 내 강의 목록, 강의 통계

8. **수강 후기 및 평점**

   - 후기 작성 (로그인 필수, 수강 완료 후 가능)
   - 후기 목록 (평점, 내용, 작성자, 작성일)
   - 평점 통계 (평균 평점, 평점 분포)

9. **반응형 디자인**
   - 모바일 (375px 이상)
   - 태블릿 (768px 이상)
   - 데스크톱 (1024px 이상)

## 🧩 데이터 모델(실습용으로 통일)

문서만 보고도 구현이 가능하려면 "데이터 구조"를 명확히 제시하는 게 좋습니다.

### 1) Course (강의)

```js
{
  id: 1,
  title: "JavaScript 기초부터 실전까지",
  instructorId: 1,
  instructor: "홍길동",  // 강사 이름 (조회 편의용)
  category: "programming",  // programming | design | marketing | others
  price: 49000,  // 0이면 무료
  thumbnail: "course-1.jpg",
  description: "JavaScript의 기초부터 실전 프로젝트까지...",
  curriculum: [
    {
      id: 1,
      title: "섹션 1: JavaScript 기초",
      order: 1,
      lessons: [
        {
          id: 1,
          title: "변수와 데이터 타입",
          videoUrl: "lesson-1.mp4",
          duration: 1200,  // 초 단위
          order: 1,
          isPreview: true  // 미리보기 가능 여부
        }
      ]
    }
  ],
  duration: 3600,  // 전체 강의 시간 (초)
  level: "beginner",  // beginner | intermediate | advanced
  rating: 4.6,  // 평균 평점
  reviews: 120,  // 후기 개수
  students: 1500,  // 수강생 수
  createdAt: "2024-01-15T10:30:00"
}
```

**공통 규칙:**

- 모든 날짜: ISO 문자열
- 모든 ID: number 또는 string 중 하나로 통일
- 카테고리: 문자열 enum 형태
- 가격: 0이면 무료 강의

### 2) Enrollment (수강 정보)

```js
{
  userId: 1,
  courseId: 1,
  progress: 65,  // 진행률 (0-100)
  completedLessons: [1, 2, 3],  // 완료한 레슨 ID 배열
  enrolledAt: "2024-01-15T10:30:00",
  lastAccessedAt: "2024-01-20T14:00:00",  // 마지막 학습 시간
  videoProgress: {
    "1": 300,  // 레슨 ID: 재생 위치 (초)
    "2": 600
  }
}
```

### 3) Review (후기)

```js
{
  id: 1,
  courseId: 1,
  userId: 2,
  userName: "김철수",  // 작성자 이름 (조회 편의용)
  rating: 5,  // 1-5점
  content: "정말 유익한 강의였습니다!",
  createdAt: "2024-01-20T10:30:00"
}
```

### 4) User (사용자)

```js
{
  id: 1,
  name: "홍길동",
  email: "hong@example.com",
  password: "hashed_password",  // ⚠️ 실서비스에서는 해시 처리 필수
  role: "instructor",  // student | instructor
  avatar: "avatar.jpg",  // 선택적
  createdAt: "2024-01-01",
  bio: "10년차 개발자입니다."  // 강사인 경우
}
```

⚠️ **보안 안내**

- 비밀번호를 localStorage에 평문으로 저장하는 방식은 실서비스에서 절대 사용하면 안 됩니다.
- 실무에서는 서버에서 해시 처리 + 토큰 기반 인증을 합니다.

## 🎨 디자인 요구사항

### 컬러 시스템

- **Primary**: `#0066FF` (주요 액션, 링크)
- **Secondary**: `#FF6600` (강조, CTA)
- **Success**: `#00CC66` (완료/성공 상태)
- **Warning**: `#FF9900` (경고)
- **Error**: `#FF3333` (오류)
- **Background**: `#FFFFFF` (배경)
- **Card Background**: `#FFFFFF` (카드 배경)
- **Text Primary**: `#1A1A1A` (주요 텍스트)
- **Text Secondary**: `#808080` (보조 텍스트)
- **Border**: `#E5E5E5` (테두리)
- **Hover**: `#F5F5F5` (호버 배경)

✅ **보완 포인트**

- CSS 변수(`:root`)로 컬러 관리 권장
- 강의 카드 호버 시 시각적 피드백
- 학습 진도 표시는 시각적으로 명확하게 (프로그레스 바)

### 타이포그래피

- **Heading 1**: Bold, 32px~48px (페이지 제목)
- **Heading 2**: Bold, 24px (섹션 제목)
- **Heading 3**: SemiBold, 20px
- **Body**: Regular, 16px (본문)
- **Caption**: Regular, 14px (보조 텍스트)
- **Small**: Regular, 12px (라벨, 날짜)

### 컴포넌트

- 강의 카드 (썸네일 + 제목 + 강사 + 가격 + 평점 + 수강생 수)
- 비디오 플레이어 (HTML5 video 또는 iframe)
- 학습 진도 바 (프로그레스 바)
- 후기 카드 (평점 + 내용 + 작성자)
- 버튼 (Primary, Secondary, Ghost)
- 입력 필드 (검색, 작성 폼)

✅ **보완 포인트**

- 모든 컴포넌트는 상태(State)가 명확해야 함: Default, Hover, Active, Disabled
- 비디오 플레이어는 접근성 고려 (자막, 키보드 제어)
