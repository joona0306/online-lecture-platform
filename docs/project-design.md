# 2단계: 디자인 - 온라인 강의 플랫폼 프로젝트

## 📚 학습 목표

이 단계를 완료하면 다음을 할 수 있습니다:

- Figma로 와이어프레임 제작(정보 구조/우선순위/수강 플로우 중심)
- 디자인 시스템 구축(색/폰트/간격 + 상태/토큰/접근성까지)
- 비디오 플레이어 UI 디자인
- 학습 진도 표시 UI 디자인
- 프로토타입 제작(핵심 사용자 흐름 검증)
- 디자인 리뷰 및 피드백 반영(근거 기반 개선)

---

## 0. 이 단계에서 반드시 만들어야 하는 "산출물"

온라인 강의 플랫폼(⭐⭐⭐⭐)은 화면이 많고 상태가 복잡해서, 디자인 단계에서 아래 산출물이 있어야 개발이 흔들리지 않습니다.

### 필수 산출물

- [ ] 와이어프레임: 메인 / 강의 목록 / 강의 상세 / 강의 수강 / 학습 대시보드 (최소 5개)
- [ ] 디자인 시스템: 컬러/타이포/간격/그리드 + 컴포넌트 상태(hover/disabled/error/loading)
- [ ] 핵심 컴포넌트: 버튼/입력/강의카드/비디오플레이어/진도바/필터UI/후기카드/페이지네이션
- [ ] 프로토타입: "강의 탐색→상세→수강 신청→수강→진도 업데이트" 흐름
- [ ] 반응형: Desktop(1440), Tablet(768), Mobile(375)
- [ ] 디자인 QA 체크: 대비/터치타겟/레이아웃 깨짐 기준

---

## 🔍 디자인 단계에서 반드시 이해해야 할 것

이 단계는 "보기 좋은 화면을 그리는 단계"가 아닙니다.  
👉 개발자가 추가 질문 없이 그대로 구현할 수 있도록 UI 결정을 끝내는 단계입니다.

### 디자인 단계의 핵심 산출물

- 모든 페이지의 레이아웃 구조
- 재사용 가능한 컴포넌트 정의
- 각 UI 요소의 상태(State)
- 비디오 플레이어 UI 명세
- 학습 진도 표시 방식
- 반응형 전환 기준

## 1. 레이아웃 디자인

### 1.1 메인 페이지 와이어프레임

#### 실습 1-1: 메인 페이지 구조 설계

**단계별 가이드:**

1. **Figma 새 파일 생성**

   - 파일명: "온라인 강의 플랫폼 - 와이어프레임"
   - 데스크톱 프레임 생성 (1440x1024)

2. **레이아웃 구조**

```
┌─────────────────────────────┐
│ 헤더 (Header)               │
│ - 로고, 네비, 검색, 로그인   │
├─────────────────────────────┤
│ 히어로 섹션 (Hero Section)   │
│ - 강력한 메시지 + CTA        │
├─────────────────────────────┤
│ 인기 강의 섹션               │
│ [강의] [강의] [강의] [강의]  │
├─────────────────────────────┤
│ 신규 강의 섹션                │
│ [강의] [강의] [강의] [강의]  │
├─────────────────────────────┤
│ 카테고리 섹션                 │
│ [카테고리] [카테고리] ...    │
├─────────────────────────────┤
│ 푸터 (Footer)               │
└─────────────────────────────┘
```

3. **기본 도형으로 구조 표현**
   - 사각형으로 각 섹션 구분
   - 텍스트로 레이블 추가
   - 회색 톤 사용

✅ 보완(중요): 메인에서 "수강으로 이어지는 정보 우선순위"

- 헤더: 로고/검색/로그인은 **항상 보이는 핵심**
- 히어로 섹션은 예쁘기보다 "강의 탐색/수강 신청" 역할이 명확해야 함
- 강의 카드에는 최소 정보(썸네일/제목/강사/가격/평점/수강생 수)가 필요

✅ 와이어프레임에 반드시 표기할 상태

- 로딩 상태: 카드가 회색 스켈레톤으로 보이는지
- 빈 상태: "강의가 없습니다" 같은 표현

**체크리스트:**

- [ ] 메인 페이지 와이어프레임 완료
- [ ] 로딩/빈 상태 같은 "상태 자리"까지 확보 완료

#### 실습 1-2: 강의 목록 페이지 와이어프레임

**레이아웃 구조:**

- 왼쪽: 필터 사이드바
- 오른쪽: 강의 그리드 (3-4열)

✅ 보완(필수): 목록 페이지는 "탐색 효율"이 핵심  
와이어프레임에서 아래 영역을 반드시 구분해 주세요.

1. 상단 컨트롤 바(우측 영역 상단)

- 결과 개수(예: 120개 강의)
- 정렬 드롭다운(인기순/최신순/가격순/평점순)
- (모바일) 필터 버튼(모달 오픈)

2. 필터 영역(좌측)

- 카테고리(체크/라디오)
- 가격 필터(무료/유료/전체)
- 난이도 필터(초급/중급/고급/전체)
- 평점 필터(최소 평점)
- "필터 초기화" 버튼(강추)
- 적용 중인 필터 칩(예: 프로그래밍 / 무료 / 초급) (강추)

3. 강의 그리드

- 카드 동일 높이(텍스트 길이 편차 대응 자리 필요)
- "결과 없음" 상태 UI 영역 확보

4. 페이지네이션(하단)

- 1 2 3 … Next
- 모바일에서는 "더보기"로 대체 가능(선택)

**체크리스트:**

- [ ] 강의 목록 페이지 와이어프레임 완료
- [ ] 결과 없음/로딩 상태 표현 영역 확보 완료
- [ ] 정렬/필터/페이지네이션 UI 자리 확정 완료

#### 실습 1-3: 강의 상세 페이지 와이어프레임

**레이아웃 구조:**

- 상단: 강의 썸네일/미리보기
- 중앙: 강의 정보 및 커리큘럼

✅ 보완(상세페이지는 "결정"이 핵심)

✅ 상태(필수)

- 이미 수강 중: "수강하기" 버튼으로 변경
- 수강 신청 성공: 토스트/모달 자리 확보

### 2.1 컬러 팔레트

#### 실습 2-1: 컬러 스타일 생성

**컬러 시스템:**

```
Primary Colors:
- Primary Blue: #0066FF
- Primary Dark: #0052CC
- Primary Light: #3399FF

Secondary Colors:
- Secondary Orange: #FF6600
- Secondary Dark: #CC5200

Neutral Colors:
- Black: #000000
- Gray 900: #1A1A1A
- Gray 800: #333333
- Gray 500: #808080
- Gray 200: #E5E5E5
- Gray 100: #F5F5F5
- White: #FFFFFF

Semantic Colors:
- Success: #00CC66 (완료, 성공)
- Warning: #FF9900 (경고)
- Error: #FF3333 (오류)
- Info: #3399FF (정보)
```

✅ 보완(중요): "토큰" 방식으로 이름을 정리하면 개발이 쉬워집니다.  
Figma 스타일 이름을 아래처럼 추천합니다(예시).

- Color/Brand/Primary
- Color/Brand/Primary-Dark
- Color/Text/Default
- Color/Text/Muted
- Color/Background/Surface
- Color/Border/Default
- Color/Semantic/Success
- Color/Semantic/Error

✅ 보완(접근성 필수)

- 본문 텍스트(16px)는 배경과 대비가 충분해야 합니다.
- Gray 500(#808080) 텍스트는 흰 배경에서 "설명/캡션" 용도로 제한하고, 본문은 Gray 800~900 사용을 추천합니다.

**Figma에서 컬러 스타일 생성:**

1. 컬러 선택
2. "Style" 아이콘 클릭 (+)
3. 스타일 이름 입력
4. 반복하여 모든 컬러 스타일 생성

**체크리스트:**

- [ ] 컬러 팔레트 정의 완료
- [ ] Figma 컬러 스타일 생성 완료
- [ ] 텍스트 컬러(본문/보조/비활성) 규칙이 문서로 남음

## 3. 컴포넌트 제작

> 온라인 강의 플랫폼은 컴포넌트가 많습니다. "몇 개만 만들어도 되겠지"가 아니라  
> 개발 단계에서 재사용하도록 최소 세트를 확정하는 게 목표입니다.

### 3.1 버튼 컴포넌트

#### 실습 3-1: 버튼 컴포넌트 만들기

**버튼 변형:**

1. **Primary Button**

   - 배경색: Primary Blue
   - 텍스트: White
   - 패딩: 12px 24px
   - Border Radius: 8px

2. **Secondary Button**

   - 배경색: Transparent
   - 테두리: Primary Blue
   - 텍스트: Primary Blue

3. **Ghost Button**
   - 배경색: Transparent
   - 텍스트: Gray 800

✅ 보완(필수): 버튼 상태(Variant) 정의

- Default / Hover / Pressed / Disabled / Loading
- Disabled는 "색만 연하게"가 아니라 **커서/대비/클릭 불가**가 느껴져야 합니다.

✅ 보완(권장): 사이즈 Variant

- S / M / L (모바일/데스크톱 대응 쉬움)
- 최소 높이 44px 권장(모바일)

**Figma에서 컴포넌트 생성:**

1. 버튼 디자인
2. 우클릭 → "Create Component" 또는 `Ctrl+Alt+K`
3. Variants로 상태 추가 (Default, Hover, Disabled)

**체크리스트:**

- [ ] 버튼 컴포넌트 생성 완료
- [ ] 버튼 변형 추가 완료

#### 실습 4-1: 핵심 플로우 프로토타입

5. **수강 → 다음 레슨**: "다음 레슨" 버튼 클릭 → 다음 레슨으로 이동
6. **검색**: 검색창 입력 → 검색 결과 페이지
7. **필터**: 필터 선택 → 강의 목록 업데이트

## 💡 문제 해결 가이드

### Q1. 비디오 플레이어 UI가 복잡해요

A: 기본 HTML5 video 컨트롤을 사용하거나, 간단한 커스텀 컨트롤만 만드는 것을 추천합니다.  
실서비스 수준의 플레이어는 라이브러리(예: Video.js)를 사용하는 것이 좋습니다.

### Q2. 학습 진도 프로그레스 바가 시각적으로 명확하지 않아요

A: 프로그레스 바 높이를 높이고, 색상 대비를 강화하세요.  
또한 진행률 숫자를 프로그레스 바 옆에 명확히 표시하세요.

### Q3. 강의 카드가 너무 많은 정보를 담고 있어요

A: 핵심 정보만 남기고 나머지는 호버 시 표시하거나 상세 페이지로 이동하도록 하세요.  
핵심 정보: 썸네일, 제목, 강사, 가격, 평점
