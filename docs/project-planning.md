## 1. 사용자 페르소나 정의

### 1.1 페르소나란?

**페르소나(Persona)**는 타겟 사용자를 대표하는 가상의 인물입니다.  
사용자의 니즈, 목표, 행동 패턴을 이해하는 데 도움이 됩니다.

✅ 보완 포인트(중요)

- 페르소나는 "프로필"이 아니라 **의사결정 기준**입니다.
- 따라서 아래 3가지를 꼭 추가하세요:
  1. _무엇이 불편한가?_ (Pain Point)
  2. _무엇이 성공인가?_ (Success Criteria)
  3. _주로 어떤 환경인가?_ (Device/상황)

## 2. 기능 명세서 작성

### 2.1 기능 명세서란?

**기능 명세서**는 웹사이트에 구현할 기능들을 "나열"하는 문서가 아니라,  
**사용자 행동 → 화면 변화 → 데이터 변화**를 구체적으로 적는 문서입니다.

✅ 보완 포인트(상 난이도에서 필수)  
기능마다 최소 아래를 적어주세요.

- 입력(Input): 사용자가 하는 행동/입력값
- 출력(Output): 화면에 보이는 결과
- 상태(State): 로딩/빈 상태/오류/성공
- 예외(Exception): 잘못된 입력/데이터 없음/네트워크 실패 등

## 3. 사이트맵 구성

### 3.1 사이트맵이란?

사이트맵은 웹사이트의 전체 구조를 시각적으로 표현한 것입니다.

### 3.2 사이트맵 작성 실습

#### 실습 3-1: 사이트맵 그리기

사이트맵 구조:

```
온라인 강의 플랫폼 웹사이트
│
├── 메인 페이지 (/)
│
├── 강의
│   ├── 전체 강의 (/courses)
│   ├── 카테고리별
│   │   ├── 프로그래밍 (/courses/programming)
│   │   ├── 디자인 (/courses/design)
│   │   ├── 마케팅 (/courses/marketing)
│   │   └── 기타 (/courses/others)
│   ├── 강의 상세 (/course-detail.html?id=101)
│   └── 강의 수강 (/course-player.html?courseId=101&lessonId=1)
│
├── 학습 대시보드 (/dashboard)
│
├── 사용자
│   ├── 로그인 (/login)
│   ├── 회원가입 (/signup)
│   └── 프로필 (/profile)
│
└── 기타
    ├── 검색 결과 (/search?q=keyword)
    └── 고객센터 (/support)
```

✅ 보완 포인트(추가)

- 실제 구현이 정적 페이지 기반이라면:
  - 상세 페이지: `course-detail.html?id=101`
  - 수강 페이지: `course-player.html?courseId=101&lessonId=1`
  - 검색/필터: `courses.html?category=programming&sort=popular&page=2`
- 처럼 "쿼리스트링" 중심으로 가는 것이 안정적입니다.

**Notion에서 사이트맵 작성:**

1. Notion 새 페이지 생성: "사이트맵"
2. 다이어그램 또는 불릿 포인트로 구조 작성
3. 각 페이지에 "역할 + 핵심 CTA(다음 행동)" 추가

**체크리스트:**

- [ ] 사이트맵 작성 완료
- [ ] 각 페이지의 역할 + 다음 행동(CTA) 정의 완료

## 4. 유저플로우 정의

### 4.1 유저플로우란?

**유저플로우(User Flow)**는 사용자가 웹사이트에서 목표를 달성하기 위해 거치는 단계별 경로를 시각화한 것입니다.  
사이트맵이 "구조"를 보여준다면, 유저플로우는 "사용자의 행동 경로"를 보여줍니다.

✅ 보완 포인트(중요)

- 유저플로우는 **"시작점 → 목표 달성"**까지의 경로입니다.
- 각 단계에서 사용자가 **무엇을 보고, 무엇을 클릭하며, 어떤 결정을 내리는지** 명확히 해야 합니다.
- **예외 상황**(강의 없음, 로그인 필요, 비디오 로딩 실패 등)도 포함해야 합니다.

### 4.2 주요 유저플로우 작성 실습

#### 실습 4-1: 핵심 강의 수강 플로우 (Happy Path)

**플로우 1: 메인 페이지에서 강의 수강까지**

```
1. 메인 페이지 접속 (/)
   └─> 히어로 섹션 확인
   └─> 인기 강의 섹션 스크롤

2. 인기 강의 카드 클릭
   └─> 강의 상세 페이지로 이동 (/course-detail.html?id=101)

3. 강의 상세 페이지
   └─> 강의 정보 확인 (제목, 강사, 가격, 평점, 설명)
   └─> 커리큘럼 확인 (섹션/레슨 목록)
   └─> 미리보기 레슨 확인 (선택)
   └─> 수강 후기 확인

4. "수강 신청" 버튼 클릭
   └─> 로그인 상태 확인
   ├─> (로그인 안 됨) → 로그인 페이지로 이동 (/login)
   └─> (로그인 됨) → 수강 신청 처리
      └─> 수강 정보 저장 (Enrollment)
      └─> "수강 신청 완료!" 알림
      └─> "수강하기" 버튼으로 변경

5. "수강하기" 버튼 클릭
   └─> 강의 수강 페이지로 이동 (/course-player.html?courseId=101&lessonId=1)

6. 강의 수강 페이지
   └─> 비디오 플레이어 확인
   └─> 첫 레슨 자동 재생 또는 재생 버튼 클릭
   └─> 커리큘럼 사이드바 확인 (현재 레슨 강조)
   └─> 학습 진도 확인 (진행률 프로그레스 바)

7. 레슨 학습
   └─> 비디오 시청
   └─> 비디오 재생 위치 자동 저장 (localStorage)
   └─> 레슨 완료 체크박스 클릭
   └─> 진도 업데이트 (completedLessons 배열에 추가)
   └─> 진행률 업데이트 (프로그레스 바)

8. 다음 레슨으로 이동
   └─> "다음 레슨" 버튼 클릭
   └─> 다음 레슨으로 이동 (URL 업데이트)
   └─> 비디오 자동 재생 또는 재생 버튼 클릭

9. 모든 레슨 완료
   └─> 마지막 레슨 완료 체크
   └─> "수강 완료!" 알림
   └─> 수강증 표시 (선택)
```

**예외 상황:**

- 강의가 없는 경우: "강의를 찾을 수 없습니다" 메시지, 목록으로 리다이렉트
- 로그인 안 됨: "로그인이 필요합니다" 알림, 로그인 페이지로 이동
- 이미 수강 중: "수강하기" 버튼으로 변경, 수강 페이지로 바로 이동 가능
- 비디오 로딩 실패: "비디오를 불러올 수 없습니다" 메시지, 재시도 버튼
- 수강 신청 안 함: "수강 신청이 필요합니다" 알림, 상세 페이지로 리다이렉트

**체크리스트:**

- [ ] 핵심 강의 수강 플로우 단계별 정의 완료
- [ ] 예외 상황 5개 이상 정의 완료

#### 실습 4-2: 검색 기반 강의 탐색 플로우

**플로우 2: 검색으로 강의 찾기**

```

   └─> "평점순" 선택
   └─> 강의 목록 재정렬

6. 강의 카드 클릭
   └─> 강의 상세 페이지로 이동
   └─> [플로우 1의 3단계부터 이어짐]
```

#### 실습 4-4: 학습 진도 관리 플로우

**플로우 4: 학습 진도 확인 및 이어서 학습**

```
1. 학습 대시보드 접속 (/dashboard)
   └─> 로그인 상태 확인
   ├─> (로그인 안 됨) → 로그인 페이지로 이동
   └─> (로그인 됨) → 대시보드 콘텐츠 표시
      └─> 학습 진도 요약 확인 (전체 진행률)
      └─> 내 강의 목록 확인 (수강 중/완료)

2. 수강 중인 강의 카드 클릭
   └─> 강의 수강 페이지로 이동
   └─> 마지막 학습 레슨으로 자동 이동 (lastAccessedAt 기반)
   └─> 마지막 재생 위치로 자동 이동 (videoProgress 기반)

3. 강의 수강 페이지
   └─> 비디오 플레이어 확인
   └─> 마지막 재생 위치에서 재생 시작
   └─> 학습 진도 확인 (진행률 프로그레스 바)
   └─> 완료한 레슨 체크 표시 확인

   └─> 비디오 시청
   └─> 비디오 재생 위치 자동 저장 (주기적으로 또는 일시정지 시)
   └─> 레슨 완료 체크박스 클릭
   └─> 진도 업데이트

5. 학습 대시보드로 복귀
   └─> "대시보드로" 버튼 클릭
   └─> 업데이트된 진행률 확인
```

**예외 상황:**

- 학습 진도가 저장되지 않음: 경고 메시지, 수동 저장 시도
- 마지막 학습 레슨이 없는 경우: 첫 레슨부터 시작
- 비디오 재생 위치가 저장되지 않음: 처음부터 재생

**체크리스트:**

- [ ] 비디오 재생 위치 저장 규칙 정의 완료

#### 실습 4-5: 회원가입 및 로그인 플로우

**플로우 5: 회원가입 후 로그인**

```
1. 메인 페이지 접속 (/)
   └─> 헤더에서 "회원가입" 또는 "로그인" 버튼 확인

2. "회원가입" 버튼 클릭
   └─> 회원가입 페이지로 이동 (/signup)

3. 회원가입 폼 작성
   └─> 이름 입력
   └─> 이메일 입력
   └─> 비밀번호 입력
   └─> 비밀번호 확인 입력
   └─> 역할 선택 (수강생/강사)
   └─> 약관 동의 체크
   └─> "가입" 버튼 클릭

4. 회원가입 처리
   └─> 유효성 검사
   ├─> (이메일 중복) → "이미 가입된 이메일입니다" 메시지
   ├─> (비밀번호 불일치) → "비밀번호가 일치하지 않습니다" 메시지
   └─> (검사 통과) → 회원가입 성공
      └─> 사용자 데이터 저장 (localStorage)
      └─> "회원가입 완료! 로그인 페이지로 이동합니다" 알림
      └─> 로그인 페이지로 이동 (/login)

5. 로그인 폼 작성
   └─> 이메일 입력
   └─> 비밀번호 입력
   └─> "로그인" 버튼 클릭

6. 로그인 성공
   └─> 세션 저장 (sessionStorage)
   └─> "로그인 성공!" 알림
   └─> 메인 페이지로 이동 (/) 또는 이전 페이지로 복귀
```

**예외 상황:**

- 이메일 형식 오류: "올바른 이메일 형식을 입력해주세요" 오류 메시지
- 비밀번호 불일치: "비밀번호가 일치하지 않습니다" 오류 메시지
- 중복 이메일: "이미 가입된 이메일입니다" 오류 메시지
- 로그인 정보 불일치: "이메일 또는 비밀번호가 올바르지 않습니다" 오류 메시지

## 💡 문제 해결 가이드

### Q1. Notion 데이터베이스가 복잡해졌어요

A: 페이지를 여러 하위 페이지로 분리하거나, 뷰(View)를 활용하여 필터링하세요.  
추가로 "이번 주 할 일" 뷰를 만들면 우선순위가 정리됩니다.

### Q2. GitHub에 push가 안 돼요

A:

- 인증 확인 (Personal Access Token 필요할 수 있음)
- 원격 저장소 URL 확인: `git remote -v`
- 최신 변경사항 먼저 pull: `git pull origin main`

### Q3. 비디오 파일이 너무 커서 GitHub에 올리기 어려워요

A: 테스트용 비디오는 작은 파일(예: 10MB 이하)을 사용하거나, GitHub LFS를 사용하세요.  
또는 로컬에서만 테스트하고 배포 시에는 외부 비디오 URL을 사용하는 방법도 있습니다.
